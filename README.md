# App Builder

เครื่องมือสร้างเว็บแอพแบบ No-code ภาษาไทย สำหรับใช้งานบนคอมพิวเตอร์ของคุณเอง เริ่มจากกำหนดตารางและคอลัมน์ แล้วสร้างหน้ารายการ ฟอร์ม และรายละเอียดจากข้อมูล

ข้อมูลและการตั้งค่าแอพเก็บในฐานข้อมูล SQLite ชื่อ `data.db` ส่วน GitHub เก็บเฉพาะโค้ด ไม่รวมข้อมูลจริง บัญชีผู้ใช้ ไฟล์สำรอง หรือรูปที่อัปโหลด

## สิ่งที่ต้องเตรียม

- Node.js พร้อม npm — สภาพแวดล้อมที่ใช้ทดสอบโปรเจกต์นี้คือ Node.js 22.12.0
- Git หากต้องการดาวน์โหลดและอัปเดตด้วยคำสั่ง หรือดาวน์โหลด ZIP จาก GitHub แทนได้
- อินเทอร์เน็ตสำหรับติดตั้งแพ็กเกจครั้งแรก

ตรวจว่าเครื่องมี Node.js และ npm แล้ว:

```powershell
node --version
npm.cmd --version
```

ตัวอย่างคำสั่งด้านล่างใช้ Windows PowerShell บน macOS หรือ Linux เปลี่ยน `npm.cmd` เป็น `npm`

## ติดตั้งครั้งแรก

### 1. ดาวน์โหลดโปรเจกต์

เปิด Terminal ในโฟลเดอร์ที่ต้องการเก็บโปรเจกต์ แล้วรัน:

```powershell
git clone https://github.com/ppshken/App-Builder.git
cd App-Builder
```

หรือกด **Code → Download ZIP** บน GitHub แตกไฟล์ แล้วเปิด Terminal ในโฟลเดอร์ที่มี `package.json`

### 2. ติดตั้งและเตรียมแอพ

```powershell
npm.cmd ci
npm.cmd run build
```

รอให้แต่ละคำสั่งเสร็จและไม่มีข้อผิดพลาดก่อนทำขั้นตอนถัดไป

### 3. เปิดใช้งาน

```powershell
npm.cmd start
```

เปิดเบราว์เซอร์ที่ **http://localhost:3000** และเปิด Terminal นี้ค้างไว้ระหว่างใช้งาน หากต้องการหยุดแอพ ให้กด **Ctrl+C** ใน Terminal

### 4. สร้างบัญชีเจ้าของแอพ

เมื่อเปิดครั้งแรกโดยไม่มีฐานข้อมูลเดิม ระบบจะให้สร้างบัญชีเจ้าของแอพ กรอกชื่อ อีเมล และรหัสผ่านความยาว 10–128 ตัวอักษร ขั้นตอนนี้ต้องทำผ่าน `localhost` บนเครื่องที่รันแอพ

ระบบสร้าง `data.db` ให้อัตโนมัติ ไม่ต้องติดตั้งเซิร์ฟเวอร์ฐานข้อมูลเพิ่มเติม

## เปิดใช้งานครั้งต่อไป

เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```powershell
npm.cmd start
```

ไม่ต้องติดตั้งหรือ build ใหม่ทุกครั้ง เปิด **http://localhost:3000** เพื่อใช้งาน

## เริ่มสร้างแอพ

- **การตั้งค่าแอพ**: ชื่อ ไอคอน สี ฟอนต์ หน้าแรก และรูปแบบหน้าจอตั้งต้น
- **Data**: ตาราง คอลัมน์ สูตร ข้อมูล และข้อมูลจริงในฐานข้อมูล
- **View**: หน้ารายการ ตาราง ฟอร์ม รายละเอียด แผนที่ กราฟ ปฏิทิน และแดชบอร์ด
- **Action**: ปุ่มแก้ไขข้อมูล เปิดฟอร์ม เปิดรายละเอียด และเรียกการทำงานอื่น
- **ผู้ใช้และสิทธิ์**: บัญชี บทบาท สิทธิ์ระดับตาราง และเงื่อนไขระดับแถว

เปิด **http://localhost:3000/run** เพื่อใช้แอพที่สร้างไว้ ขณะนี้ตัวสร้างและแอพที่สร้างยังอยู่ในโปรเจกต์และเซิร์ฟเวอร์เดียวกัน

## สำรองข้อมูลและย้ายเครื่อง

**สำรองข้อมูลก่อนอัปเดตโค้ดหรือเปลี่ยนโครงสร้างฐานข้อมูลเสมอ**

ใช้เครื่องมือสำรองข้อมูลในแอพได้ หรือหากคัดลอกไฟล์ด้วยตนเอง:

1. ปิดแอพด้วย Ctrl+C และตรวจว่าไม่มีแอพอีกหน้าต่างใช้ฐานข้อมูลเดียวกัน
2. คัดลอก `data.db` เก็บไว้ หากยังมี `data.db-wal` ให้เก็บไฟล์นั้นด้วย ห้ามคัดลอกเฉพาะ `data.db` ขณะแอพเปิดอยู่ เพราะข้อมูลล่าสุดอาจยังอยู่ใน WAL
3. เก็บโฟลเดอร์ `uploads` ด้วย หากใช้การบันทึกรูปแยกเป็นไฟล์หรือกำหนดโฟลเดอร์รูปเอง

การย้ายเครื่อง: ติดตั้งโค้ดบนเครื่องใหม่ วางฐานข้อมูลที่สำรองไว้อย่างถูกต้องในโฟลเดอร์เดียวกับ `package.json` ก่อนเปิดแอพ แล้วเข้าสู่ระบบด้วยบัญชีเดิม ตาราง สูตร View Action และบัญชีผู้ใช้จะมาจากฐานข้อมูลนั้น

GitHub ไม่ใช่สำเนาข้อมูลแอพ เพราะ `data.db`, `uploads` และ `backups` ถูกตัดออกด้วย `.gitignore`

## อัปเดตโค้ดจาก GitHub

สำรองข้อมูลและหยุดแอพก่อน แล้วรันในโฟลเดอร์โปรเจกต์:

```powershell
git pull --ff-only
npm.cmd ci
npm.cmd run build
npm.cmd start
```

ฐานข้อมูลเดิมยังใช้ต่อได้ ระบบอาจปรับโครงสร้างข้อมูลเมื่อเปิดใช้งานครั้งแรกหลังอัปเดต หาก Git แจ้งว่ามีไฟล์โค้ดที่แก้ค้างไว้ ให้จัดการไฟล์เหล่านั้นก่อนดึงเวอร์ชันใหม่

หากดาวน์โหลดแบบ ZIP ให้ใช้โฟลเดอร์โค้ดเวอร์ชันใหม่และย้ายฐานข้อมูลที่สำรองไว้มา ห้ามลบโฟลเดอร์เดิมก่อนเก็บข้อมูลเรียบร้อย

## โหมดพัฒนาและทดสอบ

สำหรับแก้โค้ดและดูผลทันที:

```powershell
npm.cmd run dev
```

ใช้แทน `npm.cmd start` และหยุดเซิร์ฟเวอร์เดิมก่อน เพื่อไม่ให้แย่งพอร์ตกัน โหมดพัฒนาจะรวบรวมหน้าจอเมื่อเปิดครั้งแรก จึงอาจช้ากว่าโหมดใช้งานปกติ

คำสั่งตรวจสอบ:

```powershell
npm.cmd test
npm.cmd run test:api
npm.cmd run test:browser
npm.cmd run build
```

ชุดทดสอบใช้ฐานข้อมูลแยกจากข้อมูลจริง เทสต์เบราว์เซอร์ใช้ Microsoft Edge ที่ติดตั้งในเครื่อง ผลทดสอบและภาพหน้าจอจะไม่ถูกนำขึ้น Git

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
| --- | --- |
| ไม่รู้จักคำสั่ง node หรือ npm | ติดตั้ง Node.js แล้วปิดและเปิด Terminal ใหม่ |
| PowerShell ไม่อนุญาตให้รัน npm.ps1 | ใช้ `npm.cmd` ตามตัวอย่าง |
| แจ้งว่าไม่มี package.json | เปิด Terminal ในโฟลเดอร์โปรเจกต์ที่มีไฟล์นี้ |
| start แจ้งว่าไม่พบ production build | รัน `npm.cmd run build` ให้สำเร็จก่อน |
| พอร์ต 3000 ถูกใช้อยู่ | หยุดเซิร์ฟเวอร์เก่า หรือใช้ `npm.cmd start -- -p 3001` แล้วเปิด http://localhost:3001 |
| ติดตั้ง better-sqlite3 ไม่ผ่าน | ตรวจเวอร์ชัน Node.js และข้อความผิดพลาด หากระบบต้องคอมไพล์แพ็กเกจเอง จะต้องมีเครื่องมือสำหรับคอมไพล์บนเครื่องนั้น |
| แผนที่ไม่มีภาพพื้นหลัง | พื้นแผนที่ OpenStreetMap ต้องใช้อินเทอร์เน็ต |

## โครงสร้างโปรเจกต์

| โฟลเดอร์ / ไฟล์ | หน้าที่ |
| --- | --- |
| `app/` | หน้าจอและ API |
| `lib/` | ฐานข้อมูล สูตร สิทธิ์ และการประมวลผล |
| `public/` | ฟอนต์และไฟล์ที่ใช้แสดงหน้าจอ |
| `tests/`, `scripts/` | ชุดทดสอบและคำสั่งช่วยทดสอบ |
| `data.db` | ข้อมูลจริงและการตั้งค่า ไม่ขึ้น Git |
| `backups/`, `uploads/` | สำเนาฐานข้อมูลและรูปที่บันทึกแยก ไม่ขึ้น Git |

ใช้ Next.js 14, TypeScript, better-sqlite3 และ CSS ธรรมดา
