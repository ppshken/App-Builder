# Data: แผนผังตาราง

เปิด Data → แผนผังตาราง หรือ /data?tab=diagram

- ใช้ metadata /api/tables ตามสิทธิ์และตารางของแอปปัจจุบัน ไม่มีการอ่านแถวข้อมูลธุรกิจ
- แสดง id ภายใน, Key, ชื่อและชนิดคอลัมน์ รวมสถานะตารางใช้ร่วมกัน
- เส้นทึบ: Ref จริงแบบหลายต่อหนึ่ง; เส้นประ: virtual Ref / List / Enum / EnumList อ้างอิง
- กดเส้นหรือปุ่มอ้างอิงเพื่อดูรายละเอียด กดชื่อคอลัมน์เพื่อเปิด ColumnEditor เดิม
- ค้นหาชื่อตาราง/คอลัมน์, ย่อขยาย, พอดีจอ, ลากหัวตาราง และจัดเรียงใหม่
- แสดงคอลัมน์เริ่มต้น 10 รายการ กดขยายได้; จัดตำแหน่งใหม่เพื่อหลบการ์ดที่ขยาย
- ตารางที่ไม่อยู่ในผล metadata ไม่ถูกนำเข้ามาในแผนผัง ปลายทางจะแสดงไม่พร้อมใช้งาน
- ตำแหน่งลากและการซูมอยู่เฉพาะรอบเปิดหน้านั้น ไม่เปลี่ยน schema หรือข้อมูล
- การแก้ไขยังใช้ API และสิทธิ์เดิม ตารางใช้ร่วมกันแก้ schema ได้จากแอปเจ้าของเท่านั้น
