## ขอบเขตและข้อสรุป

ตรวจ Diff ของงานวันนี้ทั้งส่วนโหลดสูตร Ref/Related การกรอง Slice ก่อนแบ่งหน้า การอ่าน Ref ตามรหัส และ UI ของ Action กับหน้าตั้งค่าคอลัมน์ ใช้ฐานข้อมูลทดสอบแยกสำหรับการทดสอบที่เปลี่ยนข้อมูล ไม่แก้ฐานข้อมูลจริง ไม่ Deploy และไม่เปลี่ยน Credentials, Docker Volume หรือแพ็กเกจ

ระหว่างตรวจพบปัญหาเพิ่มสองจุดในเส้นทางข้อมูล Ref และแก้พร้อมหลักฐานทดสอบไม่ผ่านก่อนแก้ รายละเอียดด้านล่าง ยังมีคำเตือนความปลอดภัยของ Next.js รุ่นเดิม และยังไม่ได้ทดสอบ Docker Runtime หรือ VPS จริง จึงไม่รับรองว่าทุกสภาพแวดล้อมพร้อมใช้งานโดยไม่มีข้อจำกัด

## ความปลอดภัยของแพ็กเกจที่ยังค้าง

ตรวจ `npm audit --omit=dev` วันที่ 18 พฤศจิกายน 2569 พบแพ็กเกจ Next.js ระดับ Moderate 1 แพ็กเกจ ซึ่งมีสองประกาศ ไม่พบ High หรือ Critical จากคำสั่งนี้ หลักฐาน `.test-data/predeploy-2026-11-18-audit.json`

- รุ่นที่ใช้อยู่: 16.4.3
- `npm audit` เสนอรุ่นแก้ไข 16.4.6
- [ประกาศข้อมูลแคชรั่วข้าม root params ผ่าน unstable_cache](https://github.com/advisories/GHSA-mfr8-8qww-v76h) ระบุรุ่นที่มีผลถึง 16.4.4 และแก้ใน 16.4.5 ตรวจข้อมูลวันที่ 18 พฤศจิกายน 2569
- [ประกาศข้อมูลแคชรั่วจาก use cache ซ้อนกันและข้อมูลสตรีมที่มาช้า](https://github.com/advisories/GHSA-vc7v-qv4w-wrv8) ระบุรุ่นที่มีผลถึง 16.4.4 และแก้ใน 16.4.5 ตรวจข้อมูลวันที่ 18 พฤศจิกายน 2569

ค้นใน `app`, `lib` และ `next.config.mjs` ไม่พบ `unstable_cache`, `use cache`, `cacheComponents` หรือ `rootParams` จึงยังไม่มีหลักฐานว่าระบบนี้เข้าถึงรูปแบบโจมตีดังกล่าวจริง ไม่สรุปว่าทั้งระบบปลอดภัยจากทุกเงื่อนไข แนะนำอัปเดตแพตช์ Next.js และทดสอบ Build/Regression แยกก่อน Production ไม่อัปเกรดอัตโนมัติในการตรวจนี้

## ส่วนที่ยังไม่ได้ทดสอบจริง

- Docker Image Build และการรัน Container: Docker Engine บนเครื่องนี้เชื่อมต่อไม่ได้ ไม่เปิด Docker Desktop หรือเริ่มบริการอื่นให้เอง หลักฐาน `.test-data/predeploy-2026-11-18-docker.log`
- Nginx/HTTPS/Volume และการเชื่อมต่อของ VPS จริง: ไม่ได้เข้าถึงหรือ Deploy
- เครื่องมือ Linux ที่ถูกข้าม 7 ข้อ โดยเฉพาะการสำรองและซ้อมกู้คืน
- iPhone เครื่องจริงและเครือข่ายมือถือ: ทดสอบเบราว์เซอร์จำลองขนาดหน้าจอและกรณีเดิมเท่านั้น
- การใช้งานพร้อมกันในจำนวนเทียบเท่า Production และการรับประกันว่าไม่มีผลกระทบทุกกรณี: ไม่ได้ทำ Load Test เต็มระบบในงานนี้
