# ตรวจความพร้อมก่อนเผยแพร่

เปิดจาก **View → ตรวจความพร้อมก่อนเผยแพร่** หรือเมนูตรวจสุขภาพและทดสอบแอพ (`/readiness`)

1. เปิดแอปหรือฉบับร่างที่ต้องการตรวจ แล้วกด **ตรวจสุขภาพแอพ**
2. เลือกตรวจสูตรกับข้อมูลตัวอย่าง หากต้องการอ่านข้อมูลสูงสุด 10 แถวต่อตาราง
3. กรอง **ต้องแก้ไข** หรือ **ข้อควรตรวจ** แล้วกด **ไปแก้ไข**
4. หลังแก้ไขให้ตรวจใหม่ ผลเดิมแสดงเวลาที่ตรวจและไม่ได้อัปเดตเอง
5. เปิด **ฉบับร่างและเวอร์ชัน → ตรวจและเผยแพร่** เพื่อตรวจฉบับร่างก่อนยืนยัน

## ผลตรวจ

- **พร้อมเผยแพร่ตามรายการที่ตรวจ**: ไม่พบข้อผิดพลาดหรือข้อควรตรวจจากรายการที่ตรวจได้
- **มีข้อควรตรวจสอบก่อนเผยแพร่**: มีคำเตือน เช่น บทบาทไม่มีเมนูที่อ่านได้ หรือไม่มีสิทธิ์อ่านตาราง Ref ปลายทาง
- **ต้องแก้ไขก่อนเผยแพร่**: มีข้อผิดพลาด เช่น สูตรผิด View อ้างคอลัมน์ที่ไม่มี หรือกฎสิทธิ์แถวผิด
- **ตรวจแล้วบางส่วน**: มีรายการที่บัญชีปัจจุบันตรวจไม่ได้ จะแสดงรายการที่ข้ามไว้

## ขอบเขต

ตรวจตารางและ Ref, สูตรแต่ละช่อง, View และคอลัมน์ของ Slice, การเรียงและจัดกลุ่ม, Inline Ref, View ปลายทาง, หน้าแรกและปุ่มเด่น, Slice, Action, Automation, PDF และงานที่ล้มเหลว

เจ้าของระบบตรวจสิทธิ์บทบาทของแอปปัจจุบันได้ด้วย: สิทธิ์เขียนที่ขาดสิทธิ์อ่าน, ตาราง Ref ที่บทบาทอ่านไม่ได้, บทบาทที่ไม่มีเมนูเข้าถึงได้ และสูตรกฎสิทธิ์แถว ผู้พัฒนาที่ไม่ใช่เจ้าของจะเห็นว่าส่วนสิทธิ์ยังไม่ได้ตรวจ โดยไม่เปิดเผยรายละเอียดบทบาท

การตรวจอ่านข้อมูลเท่านั้น ไม่เรียกใช้ Action หรือ Automation และไม่เผยแพร่แอป ข้อผิดพลาดจะป้องกันการเผยแพร่ฉบับร่างทั้งในหน้าจอและ API; คำเตือนยังต้องให้ผู้ดูแลพิจารณาเอง การแก้ไขเวอร์ชันจริงโดยตรงไม่ได้ถูกหยุดด้วยหน้าตรวจนี้

จากผลตรวจฉบับร่าง ปุ่มแก้ไขจะเปิดฉบับร่างที่ตรวจอยู่ก่อนพาไปหน้าที่เกี่ยวข้อง ส่วนสิทธิ์ผู้ใช้เป็นการตั้งค่าของเวอร์ชันจริง จึงมีปุ่มแยกที่กลับเวอร์ชันจริงก่อนเปิดหน้าจัดการสิทธิ์

ผลตรวจไม่รับรองทุกเงื่อนไขของทุกบัญชี การเชื่อมต่อภายนอก หรือข้อมูลทุกแถว ควรทดสอบขั้นตอนใช้งานจริงและตรวจใหม่เมื่อการตั้งค่าหรือสิทธิ์เปลี่ยน

## การทดสอบ

```sh
npm test
node scripts/integration.cjs publishreadiness
npm run build
```

Integration ใช้ฐานข้อมูลทดสอบแยก ตรวจสถานะทั้งสามแบบ การอ่านโดยไม่แก้ข้อมูล ตัวกรอง ลิงก์ไปแก้ไข การเปิดฉบับร่าง และ API ที่ปฏิเสธการเผยแพร่เมื่อยังมีข้อผิดพลาด
