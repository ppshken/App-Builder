# ป้องกันการบันทึกทับข้อมูล

ฟอร์มแก้ไขใน Data และแอปใช้งานจะเก็บรหัสตรวจสอบข้อมูลจริงเมื่อเปิดฟอร์ม หากรายการเปลี่ยนไปก่อนบันทึก API จะตอบ 409 และไม่บันทึกทับ ค่าที่กรอกยังอยู่ ผู้ใช้คัดลอกค่าที่ต้องการเก็บ แล้วกดโหลดข้อมูลล่าสุดเพื่อแก้ไขใหม่ได้ ระบบถามยืนยันก่อนทิ้งค่าที่กรอกไว้

ตรวจจากข้อมูลจริงของแถวนั้น ไม่รวมช่องคำนวณ ชื่อแสดงจาก Ref หรือการแก้รายการอื่น จึงไม่เตือนเมื่อสูตรเวลาเปลี่ยนโดยข้อมูลจริงยังเหมือนเดิม หากรายการถูกลบระหว่างเปิดฟอร์ม ระบบจะแจ้งว่าถูกลบแล้ว

รายการลูกที่มีการแก้ไขหรือนำออกผ่านฟอร์มแม่จะตรวจรหัสของลูกด้วย เมื่อรายการใดชนกัน การบันทึกแม่และลูกทั้งชุดจะถูกยกเลิก

ไม่ได้เพิ่มคอลัมน์ในฐานข้อมูล และไม่ล็อกฟอร์มระหว่างกรอก สูตร Action และ Automation ยังทำงานตามปกติ หากงานเหล่านั้นเปลี่ยนข้อมูลจริง ฟอร์มเก่าจะตรวจพบก่อนบันทึก

## การเรียก API จากภายนอก

GET /api/data/<table>?id=<id> จะส่ง __version มากับแถวข้อมูล ให้ส่ง __version เดิมกลับใน JSON ของ PUT /api/data/<table>?id=<id> หากได้รับ 409 ให้โหลดข้อมูลใหม่ก่อนแก้ไข ไม่ควรเปลี่ยนรหัสตรวจสอบเอง

คำขอเดิมที่ไม่ได้ส่ง __version ยังคงรองรับเพื่อรักษาการทำงานของตัวเชื่อมต่อเดิม จึงต้องส่งค่านี้เมื่อบริการภายนอกต้องการป้องกันข้อมูลชนกันเช่นเดียวกับฟอร์ม ฟอร์มที่เปิดค้างจากเวอร์ชันก่อนอัปเดตควรโหลดหน้าใหม่
