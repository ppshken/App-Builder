# ปรับประสบการณ์ออกแบบ PDF

วันที่: 16 พฤศจิกายน 2026

## สิ่งที่เปลี่ยน

- ตารางทั่วไปแสดงตัวอย่างในช่องว่างครบทุกแถว และตั้งความสูงทุกแถวให้เท่ากันได้
- ตารางลูกแสดงข้อมูลตัวอย่างตามจำนวนที่ใส่ได้จริง ความสูงแถว สัดส่วนคอลัมน์ และระยะขอบช่อง
- ตั้งแถวหน้าแรกและแถวหน้าถัดไปแยกกัน เลือกหน้าถัดไปเป็น 0 เพื่อเติมพื้นที่พิมพ์อัตโนมัติ
- มีสวิตช์ดูตัวอย่างหน้าถัดไปในกระดาษออกแบบ ตัวอย่างนี้ใช้ข้อมูลจำลอง ไม่ใช่จำนวนแถวจริง
- รูปในตารางลูกเลือกเต็มรูป (Contain) หรือเต็มกรอบ (Cover) และความสูงรายคอลัมน์ได้ รูปตัวอย่างมีสัดส่วน 160:100
- ตั้งขอบกระดาษ A4 เท่ากันทุกด้านได้ 5–40 มิลลิเมตร ค่าเดิมคือ 16 มิลลิเมตร เส้นประแสดงขอบพื้นที่พิมพ์และพื้นที่สีขาวนอกเส้นคือขอบกระดาษ
- เมื่อเปลี่ยนขอบกระดาษ ระบบปรับขนาดและตำแหน่งวัตถุให้อยู่ภายใน ย้อนกลับการปรับได้ก่อนบันทึก
- แถบหน้าด้านซ้ายแสดงภาพย่อและหน้าที่เลือก พื้นที่แคบจะย้ายเครื่องมือไว้ใต้กระดาษแทนการเบียดพื้นที่ออกแบบ
- ใช้ Ctrl หรือ Command ร่วมกับ Z เพื่อย้อนกลับ, Shift+Z หรือ Y เพื่อทำซ้ำ, D เพื่อสำเนาวัตถุ, S เพื่อบันทึก, + / - เพื่อซูม และ 0 เพื่อพอดีหน้า
- Delete / Backspace ลบวัตถุที่เลือกและไม่ได้ล็อก ลูกศรขยับวัตถุ Ctrl/Command+ล้อเมาส์ซูม และ Shift+ล้อเมาส์เลื่อนแนวนอน
- คีย์ลัดไม่แทรกการพิมพ์ในช่องกรอก สูตร หรือรายการเลือก และไม่ทำงานระหว่างบันทึกหรือเปิดหน้าต่างตัวอย่าง

## การแบ่งหน้าและความเข้ากันได้

ตัวอย่าง: กำหนดหน้าแรก 2 แถว สูงแถวละ 20 มิลลิเมตร เปิดหัวตาราง และหน้าถัดไปเป็น 0 เมื่อมีข้อมูล 25 รายการ หน้าถัดไปจะคำนวณพื้นที่จากขอบกระดาษและองค์ประกอบที่แสดงซ้ำ จึงใส่ได้มากกว่า 2 แถวโดยไม่ต้องนำหัวเรื่องหน้าแรกมาซ้ำ

กรอบหน้าแรกยังเป็นข้อจำกัดจริง หากตั้งจำนวนแถวมากกว่าที่กรอบรองรับ ระบบแสดงจำนวนที่ใส่ได้และมีปุ่มปรับกรอบตามแถวหน้าแรก โดยไม่ขยายออกนอกพื้นที่พิมพ์

แม่แบบเดิมที่ไม่มีค่าจำนวนแถวหน้าถัดไปยังคงจำนวนเดิมและวิธีเลื่อนตารางขึ้นด้านบนตามพฤติกรรมเดิม ต้องตั้งค่าใหม่เองหากต้องการเติมพื้นที่อัตโนมัติ แม่แบบใหม่ตั้งอัตโนมัติเป็นค่าเริ่มต้น

หน้าถัดไปเว้นองค์ประกอบหัว/ท้ายที่เปิดแสดงทุกหน้า และตำแหน่งตารางลูกถัดไปที่มีพื้นที่แนวนอนทับกัน หากพื้นที่ไม่พอแม้แต่หัวตารางและข้อมูลหนึ่งแถว จะหยุดสร้างรายงานพร้อมข้อความให้ปรับตำแหน่ง แทนปล่อยให้ข้อมูลล้น

## จุดเชื่อมต่อ

- lib/pdf-design.ts: ชนิดข้อมูล การตรวจค่า ขนาดพื้นที่พิมพ์ และแผนแบ่งหน้าที่ใช้ร่วมกัน
- lib/pdf-design-html.ts: แบ่งข้อมูลตามแผนและใส่รูปแบบรูปภาพในรายงาน
- lib/pdf-report.ts: ขอบกระดาษจริงและรูปแบบรูปภาพในไฟล์ PDF
- lib/workflow-config.ts: ตรวจตำแหน่งวัตถุตามขนาดพื้นที่พิมพ์และเก็บค่าขอบกระดาษ
- app/components/PdfDesigner.tsx: พรีวิว แถบหน้า ขอบกระดาษ คีย์ลัด และซูม
- app/components/PdfTableProperties.tsx: จำนวนแถว ความสูงแถว รูปภาพรายคอลัมน์
- app/components/PdfTemplateEditor.tsx และ PdfPreviewFrame.tsx: เปลี่ยนแนวกระดาษและย่อพรีวิวตามขนาดจริง
- app/components/pdf-designer.css: พื้นที่ทำงานที่ปรับตามความกว้างของตัวออกแบบ

## ข้อจำกัดที่ยังคงอยู่

รองรับกระดาษ A4 แนวตั้งและแนวนอน ยังไม่มีขอบแต่ละด้านแยกกันหรือขนาดกระดาษอื่น แถบภาพย่อแสดงหน้าที่ผู้พัฒนาออกแบบ ส่วนจำนวนหน้าที่เกิดจากข้อมูลจริงดูผ่านตัวอย่างข้อมูลจริง แถวที่มีข้อความยาวกว่าความสูงที่กำหนดจะถูกตัดภายในช่องตามรูปแบบรายงานเดิม การ์ดที่รวมหลายรูปควรเพิ่มความสูงแถวให้เพียงพอ

ทดสอบมือถือด้วยขนาดหน้าจอจำลองในเบราว์เซอร์ ยังไม่ได้ทดสอบบน iPhone เครื่องจริง ไม่ติดตั้งส่วนเสริมใหม่ ไม่แก้ฐานข้อมูลจริง และยังไม่เผยแพร่ขึ้นเซิร์ฟเวอร์
