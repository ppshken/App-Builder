# แก้ข้อความกรุณากรอกสูตรระหว่างแปลง Color เป็น Enum

## อาการ
เมื่อมีหลายแอปและเชื่อมตารางร่วม การตรวจแปลงชนิดข้อมูลอาจรายงานเฉพาะชื่อตารางต้นทางพร้อมข้อความ “กรุณากรอกสูตร” โดยไม่พบช่องสูตรที่ผิดในตารางต้นทาง

## สาเหตุที่จำลองได้
ตัวตรวจใน checkDependencies ของ lib/column-conversion.ts ตรวจ metadata ของตารางนอกขอบเขตแอป เพื่อหาการอ้างอิงกลับมายังตารางที่กำลังแปลง แต่ก่อนเรียก tableReferences ตรวจเพียงว่าค่าเป็นข้อความ ไม่ตรวจว่าข้อความว่างหรือไม่

เมื่อช่องสูตรเสริมของตารางอื่น เช่น ค่าเริ่มต้น แสดงเมื่อ หรือ Valid_If เก็บเป็นข้อความว่างหรือมีแต่ช่องว่าง ตัวแปลสูตรจึงแจ้ง “กรุณากรอกสูตร” ข้อผิดพลาดถูกส่งกลับพร้อมชื่อตารางที่กำลังแปลง ทำให้เข้าใจว่า color ของตารางนั้นขาดสูตร ทั้งที่คอลัมน์จริงไม่จำเป็นต้องมีสูตร

การเชื่อมตารางไม่ได้หมายความว่าต้องกรอกสูตรเพิ่ม และไม่ควรแก้โดยเติมสูตรในทุกช่อง

## หลักฐาน
ทดสอบก่อนแก้ด้วย Color → Enum และ metadata สูตรว่างในตารางส่วนตัวของอีกแอป ได้ผลไม่ผ่านพร้อมข้อความเดียวกัน: .test-data/color-enum-empty-formula-red.log

การอ่าน metadata ของตารางในเครื่องเป็นการอ่านอย่างเดียว ไม่แก้แถวข้อมูล และไม่พิมพ์ค่าข้อมูลจริง อย่างไรก็ตาม สาเหตุจาก Production ไม่ได้ถูกตรวจโดยเชื่อมต่อเซิร์ฟเวอร์โดยตรง

## การแก้
เพิ่มการตรวจ trim() ก่อนแปลสูตรเฉพาะขั้นตอนตรวจการอ้างอิงข้ามแอป ข้ามช่องสูตรที่ไม่ได้กำหนด แต่ยังตรวจสูตรที่มีเนื้อหา และยังปฏิเสธกรณีตารางนอกแอปมีการอ้างอิงจริงซึ่งไม่มีสิทธิ์ตรวจข้อมูล

ไม่เปลี่ยนกติกาการแปลง Color/Enum ไม่เติมค่าเอง ไม่ข้ามการตรวจค่าตัวเลือก Key Ref หรือสูตรที่ผู้ใช้กำหนด

## การทดสอบ
- ชุดหน่วยจำลอง Color → Enum พร้อมสูตรเสริมว่างในตารางนอกแอป ตรวจว่าผลพรีวิวผ่านและไม่เปลี่ยนต้นทาง
- ทดสอบว่าตารางส่วนตัวของอีกแอปยังอ่านผ่านสิทธิ์แอปต้นทางไม่ได้
- ชุดเดิมยังตรวจกรณีอ้างอิงนอกแอปจริงและปฏิเสธตามเดิม
- ทดสอบ API หลายแอป: แชร์/นำเข้าตารางสี ตรวจแปลง ยืนยันแปลง และรีเจนปลายทาง พร้อมตรวจค่าข้อมูลเดิม

หลักฐานหลังแก้:
- .test-data/color-enum-empty-formula-unit.log
- .test-data/color-enum-empty-formula-integration.log
- .test-data/color-enum-empty-formula-build.log

ทั้งหมดใช้ฐานข้อมูลจำลองแยก ไม่ Deploy และไม่เปลี่ยนข้อมูล Production

## ผลรอบสุดท้าย

- Build และตรวจชนิดข้อมูลผ่าน
- ทดสอบ Color → Enum ผ่าน API หลังแชร์ตาราง ยืนยันแปลง และรีเจนปลายทางผ่าน โดยข้อมูลจริงของ fixture ยังคงเดิม
- ทดสอบการแปลงเดิมผ่าน ทั้งพรีวิวไม่เขียนข้อมูล การยืนยัน สำรอง Ref/สูตร/รหัสเดิม token เก่า การคัดลอก EnumList Key ซ้ำ และหน้ามือถือ/ธีมมืด: .test-data/color-enum-empty-formula-regression.log
