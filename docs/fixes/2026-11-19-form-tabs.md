# แท็บและขั้นตอนในฟอร์ม

## วิธีตั้งค่า
ไปที่ View → เลือก View แบบฟอร์ม → รูปแบบหน้าจอ → จัดฟอร์มเป็นแท็บ → เปิดใช้แท็บฟอร์ม

- เพิ่มหรือเปลี่ยนชื่อแท็บ เลือกคอลัมน์และรายการลูก ย้ายลำดับแท็บ และเลือกเส้นใต้หรือปุ่มแคปซูลได้
- ช่องที่ไม่จัดแท็บอยู่ใน “ทั่วไป” แท็บที่ไม่มีช่องให้แสดงถูกซ่อนอัตโนมัติ
- ชื่อแท็บฟอร์มไม่แสดงจำนวนคอลัมน์ การตั้งค่าหน้ารายละเอียดยังคงแยกตามเดิม

## การใช้งาน
- ปุ่มหลักเป็น “ถัดไป” จนถึงแท็บสุดท้ายจึงเป็นปุ่มบันทึก
- กด “ก่อนหน้า” หรือสลับแท็บกลับได้ ค่าที่กรอกและรายการลูกร่างยังอยู่
- การไปแท็บข้างหน้าตรวจช่องบังคับ เงื่อนไขค่า และข้อผิดพลาดของแท็บก่อนหน้า
- รายการลูกแบบบังคับและเงื่อนไขรายการลูกใช้ผลตรวจจากองค์ประกอบเดิม ก่อนส่งไปตรวจฝั่งเซิร์ฟเวอร์ตามเดิม
- ยังไม่สร้างแถวระหว่างกดถัดไป บันทึกครั้งเดียวด้วยเส้นทางเดิมที่ตรวจสิทธิ์ สูตร Action และรายการลูก
- Re Open เริ่มฟอร์มถัดไปที่แท็บแรก ฟอร์มไม่เปิดแท็บยังใช้พฤติกรรมบันทึกเดิม

## โครงสร้าง
- ใช้ชนิดและการจัดกลุ่มแท็บร่วมกับรายละเอียด แต่แยกการตั้งค่า form_tabs / form_tabs_enabled / form_tabs_style
- FormTabs รักษาองค์ประกอบของแท็บที่ไม่ได้เลือกไว้ เพื่อไม่ทิ้งค่าระหว่างสลับแท็บ
- ติดตามคอลัมน์และ Ref เมื่อเปลี่ยนชื่อ/ลบ รวมถึงการโคลนแอป และตรวจความถูกต้องของ Related
- ไม่ต้องแก้โครงสร้างฐานข้อมูลจริงหรือเพิ่มแพ็กเกจ

## หลักฐานการทดสอบ
- tests/form-tabs-browser.cjs: ผ่านในฐานข้อมูลจำลอง ตรวจชื่อแท็บไม่มีจำนวน ช่องบังคับ การซ่อนแท็บจาก Show_If กดถัดไป/ก่อนหน้า เก็บค่า บันทึกเฉพาะท้ายสุด ความคงอยู่ของข้อมูล Re Open และหน้าตั้งค่า Builder
- ตรวจฟอร์มแม่ที่มีแท็บรายการลูกบังคับ: ยังไม่บันทึกเมื่อไม่มีลูก เพิ่มลูกจากฟอร์มปกติ และบันทึกแม่/ลูกสำเร็จพร้อมกัน
- tests/detail-tabs-browser.cjs: ผ่าน หน้ารายละเอียดเดิม รวมการตั้งค่า แป้นพิมพ์ มือถือ Related และการเปลี่ยนชื่อคอลัมน์/Ref
- ชุด Unit/Regression รวม: 699 ข้อ ผ่าน 692 ข้อ ข้าม 7 ข้อที่ต้องใช้ Linux ไม่พบข้อผิดพลาด (.test-data/form-tabs-unit.log)
- TypeScript ตรวจผ่าน (.test-data/form-tabs-types.log)

## ขอบเขตและข้อจำกัด
- ใช้การตรวจสิทธิ์และการบันทึกฝั่งเซิร์ฟเวอร์เดิม การแบ่งแท็บเป็นการนำทางฟอร์ม ไม่ใช่ขอบเขตสิทธิ์ข้อมูล
- ตั้งค่าเป็นราย View เพราะชื่อคอลัมน์และรายการลูกต่างกันในแต่ละตาราง
- ตรวจด้วย Edge/Chromium จำลองขนาดมือถือ ยังไม่ได้ทดสอบบน iPhone จริง
- ยังไม่ได้เผยแพร่ระบบ
