# แก้ Automation สร้าง PDF ลงคอลัมน์ไม่ได้สำหรับบทบาทที่ไม่ใช่ Owner

วันที่: 16 พฤศจิกายน 2026

## สาเหตุที่ยืนยัน

ขั้นตอน PDF สร้างข้อมูลใน _files และลงทะเบียนผู้สร้างใน _file_uploads แล้วเรียก writeRecord เพื่อบันทึกลิงก์ลงคอลัมน์ File แต่ยังไม่ได้ลงทะเบียนแอปเจ้าของไฟล์ใน _media_catalog

ระหว่าง writeRecord ระบบ checkFiles เรียก assertFileAccess ก่อนบันทึกแถว ขณะนั้นไฟล์ใหม่ยังไม่ถูกอ้างอิงในข้อมูลแถว สำหรับบทบาทที่จำกัดตามแอป ข้อยกเว้นไฟล์ที่ผู้ใช้อัปโหลดเองต้องตรงทั้งผู้สร้างและแอป เมื่อไม่มีข้อมูลแอปจึงถูกปฏิเสธด้วยข้อความ ไม่มีสิทธิ์ดาวน์โหลดไฟล์นี้ แม้ผู้ใช้มีสิทธิ์แก้ไขแถวครบแล้ว

Owner ข้ามการตรวจไฟล์ส่วนนี้ได้ จึงไม่พบอาการเดียวกัน การให้สิทธิ์แก้ไขเพิ่มไม่แก้สาเหตุ

## การแก้ไข

ปรับ lib/workflow-runner.ts ให้ขั้นตอน PDF ลงทะเบียนแอป ผู้สร้าง เวลาสร้าง โฟลเดอร์ ชื่อไฟล์ และตำแหน่งสำเนา ตามวิธีเดียวกับการอัปโหลดไฟล์ปกติ ก่อนเรียก writeRecord

การสร้างไฟล์ ลงทะเบียน บันทึกแถว และบันทึกผลขั้นตอนอยู่ในธุรกรรมเดิม หากบันทึกล้มเหลวยังคงย้อนกลับ และลบสำเนาไฟล์ด้วยกลไกเดิม ไม่เปลี่ยน assertFileAccess ไม่ข้ามสิทธิ์ตาราง สิทธิ์แถว หรือเงื่อนไขการบันทึก

## หลักฐาน

- .test-data/pdf-role-file-red.log: ทดสอบก่อนแก้ด้วยผู้ใช้จริงในฐานข้อมูลแยก บทบาทมีสิทธิ์อ่าน/แก้ไขและเรียก Action งานไม่สำเร็จ
- .test-data/pdf-role-file-reproduce.json: สถานะ failed พร้อมข้อความ ไม่มีสิทธิ์ดาวน์โหลดไฟล์นี้ โดยไม่บันทึกค่าข้อมูลส่วนบุคคล
- tests/pdf-role-file-browser.cjs: สร้างแอปและบทบาทจำลอง เข้าสู่ระบบ เรียก Action ที่สั่ง Automation สร้าง PDF บันทึกลงคอลัมน์ ดาวน์โหลด และตรวจข้อมูลแอป/ผู้สร้าง
- ทดสอบปฏิเสธการดาวน์โหลดเมื่อกฎแถวไม่อนุญาต ปฏิเสธ Action เมื่อไม่มีสิทธิ์ และปฏิเสธไฟล์จากอีกแอปแม้เป็นผู้สร้างคนเดียวกัน
- .test-data/pdf-role-file-unit.log: ผ่าน 631 ข้อ ข้าม 7 ข้อ ไม่มีข้อที่ล้มเหลว รวมกรณีป้องกันไฟล์ข้ามแอปเดิม
- .test-data/pdf-role-file-build.log: การสร้างชุดเผยแพร่ด้วยฐานข้อมูลทดสอบแยก

## ขอบเขต

ใช้กับไฟล์ที่สร้างหลังนำโค้ดใหม่ไปใช้ ไม่ย้อนแก้ทะเบียนไฟล์เก่าหรือแก้ข้อมูลจริง ไม่จำเป็นต้องลดระดับการตรวจสิทธิ์ หากผู้ใช้ไม่มีสิทธิ์แก้ไขแถวหรือคอลัมน์ งานยังต้องไม่ผ่านตามกติกาเดิม

ยังไม่เผยแพร่ขึ้นเซิร์ฟเวอร์และไม่แก้ฐานข้อมูลจริง
