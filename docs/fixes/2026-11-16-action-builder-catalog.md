# แก้สร้าง Action แล้วแจ้งชื่อซ้ำทั้งที่ไม่เห็นรายการ

## อาการและสาเหตุที่จำลองได้
เมื่อแอปเชื่อมตารางแบบอ่านอย่างเดียว Action แก้ไขหรือลบของตารางนั้นไม่ผ่านสิทธิ์กดทำงาน หน้า Builder เดิมโหลดรายการเดียวกับหน้าผู้ใช้งาน จึงซ่อน Action เหล่านั้น ทั้งที่คำนิยามยังอยู่ในแอป เมื่อเพิ่มรายการใหม่จึงสร้างชื่อ action_1 ซ้ำ

หลักฐานก่อนแก้: .test-data/action-builder-catalog-red.log แสดงว่าบันทึก Action สำเร็จ แต่รายการสำหรับจัดการคืน 0 แทน 1

## สิ่งที่แก้
- เพิ่มโหมดอ่านคำนิยามสำหรับ Builder ที่ GET /api/actions?builder=1 จำกัดผู้พัฒนาแอปและขอบเขตแอปเดิม
- หน้า Action ใช้รายการคำนิยามในการแสดง ตั้งชื่อเพิ่ม และคัดลอก ส่วน API ปกติและการกดใช้งานยังกรองสิทธิ์เหมือนเดิม
- ชื่อซ้ำจริงในแอปเดียวคืนสถานะ 409 พร้อมข้อความเฉพาะ Action ไม่แก้ทับรายการเดิม
- หากสร้างสำเร็จแต่โหลดรายการกลับล้มเหลว การลองบันทึกซ้ำใช้การแก้ไขรายการที่สร้างแล้ว ไม่ส่งสร้างชื่อเดิมซ้ำ

## การตรวจ
ทดสอบหลายแอปที่เชื่อมตารางอ่านอย่างเดียว สร้างชื่อเดียวกันในคนละแอป เลือกชนิดและบันทึกผ่านหน้าเว็บ โหลดรายการกลับ การล้มเหลวของคำขอโหลดแล้วลองใหม่ การปฏิเสธชื่อซ้ำจริง การปฏิเสธผู้ใช้ทั่วไปเข้ารายการคำนิยาม และการกด Action หลังให้สิทธิ์แก้ไข
