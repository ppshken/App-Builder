# ตัวเลือกไอคอนเต็มจอ

## การเปลี่ยนแปลง
- เพิ่มปุ่มขยายในตัวเลือกไอคอนส่วนกลาง ครอบคลุมการตั้งค่าแอป, View, Action, ตกแต่งข้อมูล และองค์ประกอบหน้าจอ
- เปิดหน้าต่างเต็มพื้นที่เบราว์เซอร์บนเดสก์ท็อปและมือถือ แสดงเริ่มต้น 384 ไอคอน เพิ่มครั้งละ 384; แบบย่อยังเริ่มต้น 96
- ค้นหาไทย/อังกฤษ กรองหมวดและรูปแบบได้ เลือกแล้วกลับหน้าตั้งค่าเดิม โดยยังต้องกดบันทึกหน้าตั้งค่าตามปกติ
- ปิดด้วยปุ่มหรือ Escape และคืนโฟกัสโดยไม่เลื่อนหน้า แยกเหตุการณ์ปิดของหน้าต่างไอคอนจากหน้าต่างภายนอก
- ใช้สีจากธีมเดิม ไม่เพิ่มแพ็กเกจหรือเปลี่ยนฐานข้อมูลจริง

## หลักฐานการทดสอบ
- tests/icon-fullscreen-browser.cjs: ผ่านในฐานข้อมูลแยก ทดสอบเต็มจอ 1440×1000 และ 390×844, 384/768 ไอคอน, ค้นหา, เลือก, ปิด, Escape, คืนโฟกัส และตรวจว่าไม่ได้บันทึกค่าโดยอัตโนมัติ
- ทดสอบ Escape ของรายการเลือกหมวดซ้อนหน้าต่างไอคอน: ปิดเฉพาะรายการหมวด
- tests/expanded-icons-browser.cjs: ผ่าน การค้นหาไทย/อังกฤษ หมวด รูปแบบ การแสดงผลมือถือ บันทึกไอคอนแอป/View/Action และรูป PWA
- บันทึกผล: .test-data/icon-fullscreen-dev-final.log และ .test-data/icon-fullscreen-regression.log
- ภาพตรวจหน้าจอ: artifacts/icon-fullscreen/mobile.png

## ข้อจำกัด
- ทดสอบเบราว์เซอร์อัตโนมัติด้วย Edge/Chromium จำลองขนาดมือถือ ยังไม่ได้ทดสอบ iPhone จริง
- ทดสอบหน้าตั้งค่าแอปโดยตรง จุดอื่นใช้คอมโพเนนต์ส่วนกลางเดียวกัน แต่ยังไม่ได้คลิกทดสอบเต็มจอครบทุกบริบท
- ไม่ได้เผยแพร่ระบบ
