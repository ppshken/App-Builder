# เพิ่มตัวเลือกไอคอนเป็น 2,418 แบบ

วันที่: 19 พฤศจิกายน 2569

## สิ่งที่เพิ่ม

- คงไอคอนเดิม 418 แบบและรหัสเดิมทั้งหมด
- เพิ่มอีก 2,000 แบบ: แบบเส้น 1,400 แบบ และแบบทึบ 600 แบบ
- ใช้ชุดเดียวกันในแอป, View, Action และการตกแต่งข้อมูล จึงไม่ต้องเปลี่ยนโครงสร้างฐานข้อมูล
- เพิ่มหมวดหมู่ภาษาไทย เช่น ยานพาหนะและรถ สุขภาพและการแพทย์ ซื้อขายและการเงิน อาคารและธุรกิจ ฐานข้อมูล ไฟฟ้า และสภาพอากาศ
- ค้นหาได้จากรหัส ชื่อ หมวดหมู่ และคำค้นที่เกี่ยวข้อง ทั้งไทยและอังกฤษตามคำแปลและคำค้นที่จัดเตรียมไว้ ชื่อเฉพาะบางไอคอนยังเป็นอังกฤษ
- ตัวอย่างคำค้น: รถยก, รถพยาบาล, โรงพยาบาล, forklift, healthcare, motorbike
- แสดงครั้งละ 96 ไอคอน กดแสดงเพิ่มเติมได้ และกลับไปจำนวนเริ่มต้นเมื่อเปลี่ยนคำค้น หมวด หรือรูปแบบ
- ไอคอนที่เลือกยังแสดงด้านบน แม้ไม่ได้อยู่ในผลค้นหาหรือกลุ่ม 96 รายการแรก

## การแสดงผลและความเข้ากันได้

ใช้ SVG Path ในโค้ดตามตัววาดเดิม ไม่มีการเรียก CDN หรือโหลดรูปจากภายนอกขณะใช้งาน ไม่มีการเพิ่ม Dependency ใน package.json

รหัสไอคอนใหม่ขึ้นต้นด้วย `tabler-` และแบบทึบลงท้าย `-solid` จึงไม่ชนกับรหัสเดิม ไอคอนเก่าไม่ได้ถูกเปลี่ยนชื่อหรือวาดใหม่ สีและขนาดยังรับจากธีมและการตั้งค่าเดิม

ไอคอนทึบใหม่เลือกเฉพาะต้นฉบับที่มี Path เดียว และใช้กฎเติมพื้นที่แบบ Nonzero ตามต้นทาง เพื่อไม่ให้พื้นที่ทึบเปลี่ยนจากการรวมรูปหลายชิ้น ส่วนไอคอนทึบเดิมยังใช้กฎเดิม สำหรับแบบเส้นที่รวม Path แยกชิ้น ปรับตำแหน่งเริ่มต้นให้เป็นพิกัดสัมบูรณ์ เพื่อไม่ให้ส่วนประกอบเลื่อนผิดตำแหน่ง

## แหล่งที่มาและใบอนุญาต

ใช้ [Tabler Icons](https://github.com/tabler/tabler-icons) จากแพ็กเกจ `@tabler/icons` รุ่น `3.52.0` ใบอนุญาต MIT ตรวจสอบจากแพ็กเกจต้นทางและ Repository ทางการวันที่ 19 พฤศจิกายน 2569

เก็บใบอนุญาตและข้อความเจ้าของลิขสิทธิ์ต้นฉบับไว้ที่ `public/licenses/tabler-icons-LICENSE.txt` เพื่อให้อยู่ในชุดเผยแพร่ด้วย ไม่ได้แก้หรือแปลข้อความใบอนุญาตต้นฉบับ

เลือกเฉพาะรูปที่ตัววาด Path เดิมรองรับได้ครบ ไม่รวมหมวดโลโก้แบรนด์ และไม่ดึง SVG หรือโค้ดใดจากผู้ใช้มารัน

## ไฟล์ที่เกี่ยวข้อง

- `lib/expanded-icons.ts`: ข้อมูลไอคอนใหม่ที่สร้างจากต้นทาง
- `scripts/generate-extra-icons.cjs`: สร้างชุดข้อมูลเดิมซ้ำได้จากแพ็กเกจรุ่นที่ระบุ ตรวจชื่อแพ็กเกจ รุ่น รูปแบบ Path และป้องกันรหัส/รูปซ้ำ
- `lib/icons.ts`: เชื่อม Catalog เดิมและคำค้นเพิ่มเติม
- `app/components/Icon.tsx`: วาดรูปทึบใหม่ให้ตรงกฎของต้นทาง
- `app/components/IconPicker.tsx`: ค้นหา หมวดหมู่ แบบเส้น/ทึบ และแสดงเพิ่มเติม
- `tests/expanded-icons.test.cjs`, `tests/expanded-icons-browser.cjs`: ตรวจ Catalog ความเข้ากันได้ การวาด และการใช้งานผ่านหน้าเว็บ

## การสร้างข้อมูลไอคอนใหม่ซ้ำ

ดาวน์โหลดแพ็กเกจ `@tabler/icons@3.52.0` ด้วย `npm pack --ignore-scripts` แล้วแตกแพ็กเกจในพื้นที่ชั่วคราว จากนั้นรัน:

```text
node scripts/generate-extra-icons.cjs <โฟลเดอร์แพ็กเกจที่แตกแล้ว>
```

ไม่ต้องติดตั้งแพ็กเกจนี้บนเซิร์ฟเวอร์จริง เพราะข้อมูล SVG และใบอนุญาตถูกเก็บไว้ใน Repository แล้ว

## ผลตรวจ

- ชุดทดสอบทั้งหมดผ่าน 691 ข้อ ข้าม 7 ข้อที่ต้องใช้ Linux ไม่มีข้อที่ล้มเหลว ตาม `.test-data/expanded-icons-tests-final.log`
- ตรวจรหัสไอคอนไม่ซ้ำ รหัสเก่ายังอยู่ Path ไม่มีเนื้อหา SVG ภายนอก และตัวตรวจของแอป/View/Action/การตกแต่งยอมรับรหัสใหม่
- ทดสอบผ่านเบราว์เซอร์และ API บนโหมดพัฒนาผ่าน ตาม `.test-data/expanded-icons-browser-dev.log`: แสดงครั้งละ 96 กดดูเพิ่ม ค้นหาไทย/อังกฤษจากคำค้น หมวด/รูปแบบ บันทึกและเปิดใหม่ มือถือ และสร้าง PNG สำหรับ PWA
- เปรียบเทียบภาพ Raster ของไอคอนทึบใหม่ครบ 600 แบบกับ SVG ต้นฉบับ พบความแตกต่าง 0 แบบ ตาม `.test-data/expanded-icons-shapes-green.json`
- Production Build ผ่าน รวม TypeScript ตาม `.test-data/expanded-icons-build-verified-final.log`
- ทดสอบบน Production Build ผ่านทั้งชุดใหม่และชุดเดิม ตาม `.test-data/expanded-icons-expandedicons-production-final.log` และ `.test-data/expanded-icons-modernicons-production-final.log`
- ตรวจชื่อไอคอนยาวบนมือถือไม่ดันจำนวนไอคอนล้นพื้นที่ โดยใช้จุดไข่ปลา ภาพหลักฐานอยู่ที่ `artifacts/expanded-icons/picker-mobile.png` และ `picker-desktop.png`

## ข้อจำกัด

ชุดข้อมูล SVG ใน JavaScript ใหญ่ขึ้นประมาณ 0.8 MB ก่อนบีบอัด การแบ่งแสดงครั้งละ 96 ช่วยจำกัดจำนวน DOM แต่ไม่ได้หมายความว่าข้อมูลไอคอนทั้งหมดถูกโหลดแยกเป็นหน้า

ยังไม่ได้ทดสอบบน iPhone/Safari จริง และไม่ได้ Deploy หรือเปลี่ยนข้อมูลจริง
