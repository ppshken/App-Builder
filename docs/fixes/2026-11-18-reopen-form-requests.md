# ตรวจและลดคำขอซ้ำตอน Reopen ฟอร์มรายการที่ตรวจ

## ผลตรวจการตั้งค่า

อ่านฐานข้อมูลบนเครื่องพัฒนาแบบอ่านอย่างเดียว พบฟอร์ม `view_60` ของ Inspection EDIT เปิด Reopen และกำหนด Action หลังบันทึก `action_4` ซึ่งเปลี่ยนหน้าเมื่อจำนวนรายการครบ หรือค่า `lock_pass` เป็นจริง Action จึงต้องมีลำดับก่อน Reopen ตามเดิม

Automation สามตัวที่ผูกกับตารางนี้ในฐานข้อมูลที่ตรวจปิดอยู่ทั้งหมด ข้อมูลนี้เป็นสถานะของเครื่องพัฒนา ไม่ยืนยันว่าสถานะบน VPS เหมือนกัน ไม่แก้สูตรหรือการตั้งค่าแอปจริง

## การปรับ

- ตอนเพิ่มแถวใหม่แล้ว Reopen ไม่รออ่านแถวที่เพิ่งบันทึกด้วย `GET ?id=...` เพราะฟอร์มถัดไปต้องใช้ค่าตั้งต้นใหม่ ไม่ใช่ค่าของแถวที่เพิ่งบันทึก การแก้ไขแถวเดิมและการกลับไปหน้ารายละเอียดยังคงอ่านและใช้ข้อมูลล่าสุดตามเดิม
- Reopen ไม่เรียก `create_check=1` ซ้ำก่อน `defaults=1` เพราะ API ค่าตั้งต้นตรวจสิทธิ์และเงื่อนไขเพิ่มอยู่แล้ว การเปิดฟอร์มครั้งแรกยังตรวจล่วงหน้าเหมือนเดิม และฝั่งบันทึกยังตรวจอีกครั้ง
- ยังคงโหลดสูตรและค่าตั้งต้นใหม่ทุกครั้ง ไม่แคชข้ามรอบ เพราะสูตรต้องเห็นรายการที่เพิ่งบันทึกและเลือกข้อถัดไปให้ถูกต้อง

## การทดสอบ

เพิ่ม `tests/reopen-fast-browser.cjs` ใช้ฐานข้อมูลจำลองแยก ไม่บันทึกข้อมูลลงฐานจริง

- ก่อนปรับ พบคำขอหลักหนึ่งรอบเป็นบันทึก 1 ครั้ง อ่านแถวที่บันทึก 1 ครั้ง ตรวจเพิ่ม 1 ครั้ง ค่าตั้งต้น 1 ครั้ง และข้อมูลสูตร 1 ครั้ง หลักฐาน `.test-data/reopen-fast-red.log`
- หลังปรับ เหลือบันทึก 1 ครั้ง ค่าตั้งต้น 1 ครั้ง และข้อมูลสูตร 1 ครั้ง ไม่มีคำขออ่านแถวที่เพิ่งบันทึกหรือการตรวจเพิ่มซ้ำ นับเฉพาะเส้นทางหลักนี้ ไม่รวม Dropdown หรือ Realtime อื่น
- สูตรเลือกข้อถัดไปเลือก 1, 2, 3, 4 ตามข้อมูลที่บันทึกแล้ว โดยไม่เลือกซ้ำ
- Action เพิ่มตัวนับทำงานครั้งเดียวต่อแถว
- หากโหลดค่าตั้งต้นล้มเหลว การกดลองเปิดใหม่ไม่เพิ่มแถวซ้ำ และปุ่มบันทึกค้างปิดไว้จนเปิดฟอร์มรอบใหม่สำเร็จ
- เมื่อไม่ผ่านเงื่อนไขเพิ่ม API ค่าตั้งต้นยังปฏิเสธ ไม่เปิดฟอร์มใหม่แม้เอาคำขอตรวจล่วงหน้าที่ซ้ำออก
- Action เปลี่ยนหน้าเมื่อทำครบยังมีลำดับก่อน Reopen

หลักฐานผ่าน `.test-data/reopen-fast-reopenfast.log` และ `.test-data/reopen-fast-serial.log` การวัดในสคริปต์รอบแยกได้ประมาณ 152 มิลลิวินาทีจากกดบันทึกถึงฟอร์มใหม่ ส่วนก่อนปรับได้ประมาณ 265 มิลลิวินาที เป็นข้อมูลจำลองและวัดครั้งเดียว ไม่ใช่คำรับประกันเวลาเครื่องจริงหรือ iPhone

Build ผ่าน รหัสจบงาน 0 ใช้ฐานข้อมูล Build แยก หลักฐาน `.test-data/reopen-fast-build-final.log` โดยเครื่องมือหยุดแจ้งเตือน Next.js รุ่นเดิมในรอบแรกแล้วจึงรันซ้ำ ไม่เปลี่ยนแพ็กเกจ

การทดสอบสิทธิ์เพิ่มและฟอร์มเดิมผ่าน `.test-data/reopen-fast-createguard.log` รวมการตรวจพร้อมกันและการไม่ให้ Action ข้ามเงื่อนไข การทดสอบบันทึกพร้อมอัปเดตแถวแม่และย้อนกลับทั้งชุดผ่าน `.test-data/reopen-fast-savingworkflow.log`

ไม่ Deploy ไม่เปลี่ยนฐานข้อมูลจริง และไม่ลดการตรวจสูตรหรือสิทธิ์ฝั่งเซิร์ฟเวอร์
