# พื้นที่พัฒนาแม่แบบ PDF และขอบเขตตรวจเวอร์ชันจริง

## สิ่งที่ตรวจยืนยันได้
การแก้แม่แบบ PDF ผ่าน API และหน้าเว็บของพื้นที่พัฒนาแยกจากแม่แบบจริงถูกต้อง การแก้ PDF เพียงอย่างเดียวไม่ทำให้เกิดข้อความเวอร์ชันจริงเปลี่ยน

พบข้อผิดพลาดอีกกรณีที่จำลองได้: สร้างพื้นที่พัฒนาของแอปหนึ่ง แล้วมีอีกแอปเพิ่มตารางของตัวเอง ตัวเปรียบเทียบแผนที่แยกขอบเขตแอประบุว่า liveChanged เป็น false แต่ตัวตรวจ hash แบบเก่าที่รวมโครงสร้างทุกแอปยังระบุ conflict เป็น true และเพิ่มตัวบล็อก LIVE_CHANGED

หลักฐาน: .test-data/development-pdf-isolation-red.log มีผล legacyConflict: true, scopedLiveChanged: false และ liveBlocker: true

ยังไม่มีข้อมูลเพียงพอจะยืนยันว่า Production ของผู้ใช้เกิดจากกรณีนี้โดยตรง และไม่มีการเชื่อมต่อไปแก้ Production

## การแก้ไข
- พื้นที่พัฒนาโครงสร้างใช้ผลเปรียบเทียบเฉพาะค่าตั้งแอป ตารางที่แอปเป็นเจ้าของ และตารางร่วมที่เชื่อมอ่านได้
- ยังปฏิเสธการเปลี่ยนแปลงจริงของแอปเดียวกันหรือตารางร่วม ไม่รวมการแก้ไขชนกันอัตโนมัติ
- ก่อนใช้แค็ตตาล็อกฉบับร่างระหว่างซ้อมและเผยแพร่ เก็บข้อมูลโครงสร้างตาราง คอลัมน์ และค่าตารางร่วมที่อยู่นอกขอบเขตแอปจากข้อมูลจริงล่าสุด เพื่อไม่ย้อนหรือเขียนทับของแอปอื่น
- ใช้ฟังก์ชันกำหนดขอบเขตร่วมกันระหว่างการวางแผนและการทำงานจริง
- ฉบับร่างแบบตั้งค่าเดิมยังใช้การตรวจ hash รวมเหมือนเดิม เนื่องจากกลไกเผยแพร่เดิมยังไม่ได้แยกขอบเขตเช่นพื้นที่พัฒนาโครงสร้าง
- เปลี่ยนหมายเลขตัวประมวลผลให้ผลซ้อมเก่าหมดความน่าเชื่อถือ ต้องซ้อมใหม่ ไม่ยอมใช้ผลซ้อมจากกลไกเดิมมาเผยแพร่ทันที

## แนวทางใช้งานหลังอัปเดตโค้ด
เปิดพื้นที่พัฒนาเดิม ตรวจและเผยแพร่ แล้วซ้อมใหม่ หากการเปลี่ยนเป็นของแอปอื่นที่ไม่เกี่ยวข้อง จะไม่ต้องสร้างพื้นที่พัฒนาใหม่เพราะกรณีนี้ แต่หากค่าจริงในแอปเดียวกันหรือตารางร่วมเปลี่ยนจริง ระบบยังบล็อกเพื่อป้องกันเขียนทับ

## การทดสอบ
- ทดสอบก่อนแก้และหลังแก้ด้วยฐานข้อมูลจำลองหลายแอป
- แก้ PDF ผ่าน API และหน้าเว็บ พร้อมตรวจว่าแม่แบบจริงยังเหมือนเดิม
- เพิ่มคอลัมน์คำนวณในพื้นที่พัฒนา แล้วให้อีกแอปเพิ่มตาราง/คอลัมน์เพื่อทดสอบการจัดรหัสและรักษาโครงสร้างนอกขอบเขต
- ซ้อมและเผยแพร่จริงในฐานข้อมูลทดสอบ ตรวจ PDF และคอลัมน์คำนวณใหม่ พร้อมตรวจว่าโครงสร้างและข้อมูลของอีกแอปไม่เปลี่ยน
- เปลี่ยน PDF จริงของแอปเดียวกันหลังสร้างพื้นที่ แล้วตรวจว่ายังบล็อก
- ทดสอบหน่วยยืนยันว่าตารางร่วมที่เชื่อมอ่านได้ยังอยู่ในขอบเขตตรวจ

- ทดสอบซ้อมและเผยแพร่ PDF พร้อมคอลัมน์คำนวณหลังแอปอื่นเพิ่มตาราง/คอลัมน์ผ่าน โดยข้อมูลและโครงสร้างล่าสุดของอีกแอปไม่เปลี่ยน
