# จัดกลุ่มรายการตารางตามแอปต้นทาง

หน้า **ตารางและสิทธิ์ → จัดการตารางและสิทธิ์** เปลี่ยนรายการตารางแบบรวมเป็นกลุ่มตามแอปเจ้าของตาราง

## การแสดงผล

- หัวกลุ่มแสดงรูปหรือไอคอนจริง ชื่อแอป และจำนวนตาราง
- แสดงแอปปัจจุบันก่อน พร้อมป้ายกำกับ และเปิดกลุ่มนี้เริ่มต้น
- กลุ่มแอปอื่นเริ่มต้นแบบย่อ กดหัวกลุ่มเพื่อขยายหรือย่อรายการตารางได้
- เพิ่มปุ่มขยายทั้งหมดและย่อทั้งหมด
- ค้นหาได้ทั้งชื่อแอป ชื่อตารางที่แสดง และชื่อในระบบ ผลค้นหาจะเปิดกลุ่มที่ตรงเงื่อนไขให้เห็นตาราง
- รองรับหน้าจอมือถือและธีมมืด พร้อมการเลื่อนรายการในกรอบเดิม
- ปรับการวนโฟกัสด้วยแป้น Tab ให้รวมหัวกลุ่ม และข้ามช่องที่ซ่อนอยู่ในกลุ่มที่ย่อ

## สิทธิ์และข้อมูล

ใช้รายการตารางและข้อมูลแอปจาก API เดิม จัดกลุ่มด้วย `owner_app_id` ไม่จัดจากชื่อที่อาจซ้ำกัน

การติ๊กอ่าน เพิ่ม แก้ไข ลบ และ Excel ยังคงบันทึกทันที ตารางของแอปปัจจุบันยังแสดงสิทธิ์ที่กำหนดจากเจ้าของและไม่เปิดให้แก้ผ่านหน้านี้เหมือนเดิม ไม่มีการเปลี่ยนกติกาสิทธิ์ฝั่งเซิร์ฟเวอร์หรือโครงสร้างฐานข้อมูล

## ไฟล์

- `app/apps/ApplicationAccessEditor.tsx` — กลุ่มแอป ค้นหา ย่อ/ขยาย รูปแอป และการโฟกัส
- `app/apps/application-access-groups.css` — รูปแบบหัวกลุ่มและรายการตาราง
- `tests/access-groups-browser.cjs` — ทดสอบแอปจำลองสามแอป การแสดงรูป การค้นหา การขยาย และการบันทึกสิทธิ์
- `scripts/integration.cjs` — เพิ่มชุดทดสอบ `accessgroups`
