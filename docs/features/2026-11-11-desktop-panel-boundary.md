# แก้พื้นที่หน้ารายการทับแผงรายละเอียดบนเดสก์ท็อป

## ปัญหาที่ตรวจพบ

หน้ารายการ แผงรายละเอียด และปุ่มที่ยึดกับหน้าจอคำนวณความกว้างจากพื้นที่อ้างอิงต่างกัน เมื่อมีเมนูด้านซ้ายจึงเกิดขอบเหลื่อมกัน โดยจำลองได้ที่หน้าจอ 1920 พิกเซล:

- แผงรายละเอียดเริ่มที่ตำแหน่ง 1344 พิกเซล
- พื้นที่รายการสิ้นสุดที่ประมาณ 1359 พิกเซล จึงล้ำเข้าแผงประมาณ 15 พิกเซล
- แถบแบ่งหน้าสิ้นสุดที่ประมาณ 1363 พิกเซล จึงล้ำเข้าแผงประมาณ 19 พิกเซล

หลักฐานก่อนแก้: `.test-data/desktop-panel-boundary-before.log`

## วิธีแก้

แก้ที่ `app/runtime-layout.css` ให้เดสก์ท็อปใช้ตัวแปร `--runtime-detail-width` ร่วมกัน โดยอ้างอิงความกว้างหน้าจอหลังหักเมนูด้านซ้าย แล้วนำไปใช้กับ:

- แผงรายละเอียด ฟอร์ม และฟอร์มลูกด้านขวา
- พื้นที่รายการด้านซ้าย โดยเผื่อระยะขอบเดิมของหน้าจอ
- ความกว้าง Pagination และตำแหน่งปุ่มเพิ่ม

กำหนดลำดับการซ้อนของพื้นที่รายการด้วย `isolation: isolate` เพื่อไม่ให้แถบเครื่องมือที่ตรึงอยู่ล้ำชั้นการแสดงผลของแผงรายละเอียด และเพิ่มความเฉพาะเจาะจงของตัวเลือก CSS เพื่อให้ใช้ขอบเขตเดียวกันได้ทั้งรูปแบบพัฒนาและ Production Build

การเปลี่ยนนี้ไม่ได้แก้ข้อมูล สิทธิ์ สูตร หรือระบบเปิด–ปิดหน้า

## การตรวจสอบ

- ทดสอบด้วยตารางที่มีหลายคอลัมน์จนต้องเลื่อนแนวนอน
- ตรวจขอบเขตของรายการ ช่องค้นหา ปุ่ม Excel/กรอง ตาราง Pagination และปุ่มเพิ่ม
- ทดสอบหน้าจอ 1024, 1440 และ 1920 พิกเซล ทั้งเมนูพับและเมนูขยาย
- ตรวจการเปิดรายละเอียดจากแถว และเปิดผ่านลิงก์โดยตรง รวมถึงเปิดแก้ไขและใช้งานปุ่มกรองจากหน้ารายการด้านหลัง
- ตรวจว่าแผงรายละเอียดรับการคลิกในพื้นที่ของตนเอง
- ตรวจมือถือและแท็บเล็ตที่ 390 และ 960 พิกเซลว่าแผงยังเต็มหน้าจอหลังแอนิเมชันสิ้นสุด
