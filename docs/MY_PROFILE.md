# โปรไฟล์ของฉัน

เปิดจากรูปโปรไฟล์บน Header หรือเมนูโปรไฟล์ของฉันในหน้าแอป และชื่อผู้ใช้บน Header หน้าจัดการ

- แสดงอีเมล บทบาท และสถานะบัญชีที่ล็อกอิน อีเมลและบทบาทแก้ได้เฉพาะผู้ดูแลในผู้ใช้และสิทธิ์
- แก้ชื่อและรูป JPG/PNG/WebP รูปต้นฉบับไม่เกิน 10 MB ฝั่งหน้าจอย่อด้านยาวไม่เกิน 384 px และบันทึกเป็น JPEG
- รูปบัญชีใช้ใน Header ก่อนแหล่งรูปจากค่าตั้งค่าผู้ใช้เดิม หากไม่มีรูปบัญชียังใช้ค่าเดิมได้
- เปลี่ยนรหัสผ่านต้องกรอกรหัสเดิมและยืนยันรหัสใหม่ ความยาว 10–128 ตัวอักษร ตรวจสอบด้วย scrypt และใช้ login throttle เดิม
- เปลี่ยนรหัสผ่านยกเลิก session อุปกรณ์อื่น แต่คงอุปกรณ์ที่เปลี่ยนไว้
- ออกจากระบบ / ออกจากระบบทุกอุปกรณ์ใช้ระบบเดิม

API /api/auth/profile อ่านและแก้บัญชีจาก session เท่านั้น ไม่รับตัวระบุผู้ใช้หรือบทบาทจาก client ตรวจ same-origin ก่อน PATCH และไม่ผ่านฐานข้อมูลฉบับร่าง

ตาราง _user_profiles แยกข้อมูลรูปจาก _users จัดเป็นตารางบัญชีในการสำรองและกู้คืน การเริ่มระบบอัปเกรด schema พร้อมกลไกสำรองเดิม รูปเป็น data URL จำกัดรูปแบบ raster และขนาดคำขอ

ทดสอบ: node scripts/integration.cjs profile ใช้ฐานข้อมูลแยก ทดสอบบัญชีไม่มีสิทธิ์ builder แก้บัญชีตนเอง ป้องกันเปลี่ยนอีเมล/บทบาท/บัญชีคนอื่น หน้า UI มือถือ เปลี่ยนรหัสผ่านและยกเลิก session อื่น ไม่มีการทดสอบบน iPhone จริง
