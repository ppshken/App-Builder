# หน้ากำหนดเอง รุ่นสอง

เปิด View → กำหนดเอง → เปิดตัวออกแบบ แบบเดิม version 1 ยังใช้ได้ เมื่อแก้ไขจะบันทึกเป็น version 2

## องค์ประกอบใหม่
- ข้อมูลจาก View: ฝังตาราง รายการ แผนที่ กราฟ หรือปฏิทิน ใช้ Slice/คอลัมน์/สิทธิ์ของ View เดิม มีปุ่มเปิดหน้าเต็ม ไม่อนุญาตฝัง Custom/Dashboard ซ้อน
- ตัวชี้วัด: ชื่อและค่าจากสูตร เช่น COUNT(jobs[id]), SUM(jobs[amount])
- ฟอร์ม: เปิด View ฟอร์มจริง พร้อมสูตรค่าตั้งต้นแต่ละคอลัมน์ รองรับ Ref/EnumList/รูปภาพ/รายการลูก/การตรวจข้อมูลและ Action หลังบันทึกผ่านฟอร์มเดิม เลือกสูตร id เพื่อเปิดแก้ไขได้
- ปุ่ม: เปิด View/รายละเอียดตามสูตร id, เรียก Action ตามสูตร id, ย้อนกลับ หรือโหลดข้อมูลใหม่ การลบและ Action ที่มีคำยืนยันต้องยืนยันก่อน

## การปรับแต่ง
ข้อความ/รูป/ปุ่มใช้ค่าจากสูตรได้ มี Show_If และสูตรปิดปุ่ม เลือกแสดงเฉพาะมือถือหรือจอใหญ่ ความกว้างเปอร์เซ็นต์ ความสูงขั้นต่ำ เส้นขอบ เงา และไอคอน มีตัวช่วยเขียนสูตรและปุ่มเพิ่มชุดหน้าเริ่มต้น กดดู Preview เพื่อทดสอบกับ runtime เดิม

สูตรไม่มีแถวปัจจุบัน ใช้ SELECT, LOOKUP, ANY และตาราง[คอลัมน์] แทน [คอลัมน์] การอ่านใช้ GET /api/expression-data เดิม แบ่งชุดสูตรและรวมตารางที่อ่านได้ในรอบโหลด ไม่มี API ใหม่หรือข้อยกเว้นสิทธิ์ เมื่อบางสูตรอ่านไม่ได้จะแสดงข้อผิดพลาดเฉพาะองค์ประกอบ

สูตรข้ามตารางใช้ขีดจำกัดเดิมของระบบ (snapshot สูงสุด 10,000 แถวต่อตาราง) หากเกินจะแจ้งข้อผิดพลาด ไม่คำนวณจากข้อมูลที่ถูกตัดทิ้ง เฉพาะข้อมูลฝัง View ใช้ pagination ของ View เดิม

Action เรียก POST /api/actions และฟอร์มใช้ API ข้อมูลเดิม ทุกการอ่าน/เขียนตรวจสิทธิ์บนเซิร์ฟเวอร์ ฝั่ง UI ไม่ใช่ด่านสิทธิ์การบันทึก Show_If ขององค์ประกอบใช้จัดหน้าจอ ไม่ใช่การกำหนดสิทธิ์ตาราง

หน้าตรวจสุขภาพ การแปลงคอลัมน์ และการตรวจไฟล์สำรองตรวจสูตร/Action/ค่าตั้งต้นร่วมกัน หลังเปลี่ยนชื่อ schema ต้องปรับสูตรองค์ประกอบที่อ้างชื่อเดิมด้วย รุ่นนี้ไม่ได้เพิ่มกลไกเปลี่ยนชื่อสูตร schema อัตโนมัติ

ปิดตัวออกแบบเก็บ draft ไว้ ยังต้องกดบันทึก View การ Preview และเปิดฟอร์ม/Action ใน runtime ทำงานกับข้อมูลจริงตามสิทธิ์
