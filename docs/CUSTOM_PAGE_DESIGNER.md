# View กำหนดเอง — ระยะที่ 1

View → เพิ่ม Primary หรือ Menu View → รูปแบบหน้าจอ “กำหนดเอง” → ตั้งชื่อ → เปิดตัวออกแบบ

- ไม่ต้องมีตารางหลัก สร้างได้แม้แอปยังไม่มีตาราง
- ซ้าย: องค์ประกอบและโครงสร้าง กลาง: หน้าจอ ขวา: คุณสมบัติ
- Column, Row, Container, ข้อความ, รูปภาพจาก URL, ปุ่มเปิด View, เส้นแบ่ง, ช่องว่าง
- กดเพิ่มในกล่องที่เลือก หรือลากจากคลัง; ย้ายองค์ประกอบจาก canvas/โครงสร้าง หรือใช้ตัวเลือกกล่องปลายทางและปุ่มขึ้นลง
- ปรับข้อความ ขนาด/ความหนาอักษร สี ระยะขอบ/ห่าง มุมโค้ง และรูปภาพ
- Row เรียงแนวตั้งอัตโนมัติเมื่อพื้นที่หน้าไม่เกิน 600px ปิดได้ต่อ Row
- ทดสอบจอ 375/768/1200px และซูม 50/75/100%; มือถือมีแท็บสลับแผง
- ย้อนกลับ/ทำซ้ำภายในตัวออกแบบได้ 60 ขั้น รวมสำเนาและลบ
- บันทึก View ใช้กลไกเดิม ปุ่มจางเมื่อไม่มีการเปลี่ยนแปลง; ปิดตัวออกแบบเก็บ draft ไว้จนกดบันทึกหรือยกเลิกจากหน้า View

โครงสร้าง version 1 เก็บที่ display.custom_page ใน display_json ของ View ภายใต้แอปปัจจุบัน ไม่มี schema/table ใหม่และไม่มีการแก้ข้อมูลธุรกิจ

ใช้ CustomPage แสดงผลทั้ง canvas และ runtime; ปุ่มใช้งานเฉพาะ View ที่ผู้ใช้เห็นตามสิทธิ์/Show_If และไม่เป็น Inline/Detail ที่ต้องใช้แถว เรียก onNavigate เดิม ไม่เปิด URL ตามอำเภอใจ

ตัวตรวจสอบจำกัด 100 องค์ประกอบ/8 ชั้น/80 KB และปฏิเสธ HTML, JS, CSS หรือ URL แทรกสคริปต์ ไม่ render HTML ดิบ รองรับไฟล์สำรองหลายแอปและการตรวจสุขภาพระบบ

ขอบเขตระยะนี้: เนื้อหาคงที่และปุ่มเปิด View ยังไม่มีผูกข้อมูล/สูตรกับองค์ประกอบ, ตารางย่อย, ช่องฟอร์ม หรือเรียก Action โดยตรง
